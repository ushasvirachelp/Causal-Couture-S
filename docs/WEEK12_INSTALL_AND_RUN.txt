The CLI reuses existing Phase 5 estimators when you choose --unified-csv.
For large data this may take some time due to bootstrap diagnostics.
The --input-json option is faster and does not rerun estimation.

The review flags execution gaps, disagreement between row and SKU-cluster
bootstrap interval interpretations, simulated confounding direction changes,
poor observed engagement variation, and inventory pressure. It also records
placebo coefficients for MANUAL comparison, without arbitrary pass/fail cutoffs.
It NEVER certifies causality or recommends automated business actions.
