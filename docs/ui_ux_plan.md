# Causal Couture — UI/UX Plan

## Product Goal

The interface should feel like a modern fashion analytics product rather than a technical demo.

The user should be able to understand the workflow without needing to understand the backend.

## Main Navigation

The application will use five primary sections:

1. Overview
2. Data
3. Intelligence
4. Scenario Lab
5. Insights

## User Journey

Upload
→ Validate
→ Integrate
→ Analyze
→ Simulate
→ Decide

## Overview

The overview should present the most important business signals immediately.

Planned cards:

- Demand Pressure
- Stock Risk
- Engagement Momentum
- Conversion Strength
- Overall Signal

Each card should show:

- current score
- status label
- trend direction
- percentage change when available

## Data Section

The data section should show the status of each source:

- Sales
- Inventory
- Social
- Web

Each source should show whether data is:

- missing
- uploaded
- validated
- processed

Technical JSON output should not be displayed by default.

It should be placed inside an expandable technical-details section.

## Intelligence Section

Display:

- current recommendation
- priority
- business explanation
- major trends
- alerts

## Scenario Lab

The Scenario Lab should allow users to adjust:

- demand
- inventory
- engagement
- conversion

Controls should use sliders and numeric values.

The user should be able to:

- run scenario
- reset scenario
- compare baseline and scenario values

## Insights Section

The insights section will contain:

- major alerts
- recommendation rationale
- trend summaries
- explanation text

## Navigation Behavior

Planned UX behavior:

- sticky navigation
- smooth scrolling
- active section highlighting
- scroll progress indicator
- back-to-top button

## Interaction States

Buttons should support:

- default
- hover
- loading
- disabled
- success
- error

## Feedback

The interface should provide:

- upload success messages
- validation errors
- loading indicators
- scenario completion confirmation
- error notifications

## Accessibility

The interface should include:

- visible keyboard focus states
- readable contrast
- responsive layout
- descriptive labels
- clear button states

## Visual Direction

The product should use a restrained fashion-editorial aesthetic.

Initial palette:

- Ivory: #F7F5F0
- Ink: #171716
- Plum: #583C4B
- Dusty Rose: #B78D91
- Stone: #A59E96
- Sage: #76806C
- White: #FFFFFF

The design should prioritize:

- whitespace
- typography
- hierarchy
- subtle borders
- restrained animation
- easy scanning

The interface should feel polished and positive without becoming overly decorative.
