# Causal Couture — Phase 4 Plan

## Objective

Phase 4 will extend the current analytical prototype into a more interactive decision-support system.

The focus is scenario intelligence, trend monitoring, improved recommendations, and a stronger user experience.

## Planned Components

### Scenario Analysis

Allow users to simulate changes in:

- demand
- inventory
- engagement
- conversion

The system will compare:

baseline metrics

against

scenario-adjusted metrics

### Trend Intelligence

Add recent-period versus previous-period comparisons for:

- demand
- inventory
- engagement
- conversion

Each metric should return:

- direction
- percentage change
- trend label

### Recommendation Engine

Expand recommendation logic into structured actions such as:

- REORDER
- MONITOR
- HOLD
- DEPRIORITIZE

Each recommendation should include:

- priority
- reason
- confidence
- recommended action

### Alerts

Create rule-based alerts for:

- high demand with falling inventory
- low stock
- sales spikes
- high engagement with weak conversion
- conversion decline

### Executive Dashboard

Create a cleaner dashboard that presents:

- KPI cards
- trend indicators
- recommendation cards
- alerts
- scenario comparison
- dataset status

### UI/UX Improvements

Improve the user experience with:

- sticky navigation
- smooth scrolling
- active navigation states
- loading indicators
- success and error messages
- collapsible technical details
- better empty states
- responsive layout
- keyboard focus states
- scenario reset controls

## Phase 4 Boundary

Phase 4 will not claim causal inference.

Scenario outputs will be clearly labeled as simulations.

Full causal effect estimation belongs to the next development phase.
